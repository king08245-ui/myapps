# 비공개 테스트 안내 — 개인 개발자 계정용

새 개인 계정은 **테스터 12명 이상이 14일 연속** 참여한 비공개 테스트를 마쳐야 정식 출시(프로덕션) 신청이 열립니다. 중간에 빠져 12명 아래로 내려가면 14일이 다시 시작될 수 있으니 **15~20명**을 모으세요. 채널 맛집수첩과 같은 테스터 그룹을 함께 써도 됩니다.

## 1. 테스터 모집 카톡 문구 (복사해서 보내기)
> 안녕하세요! 제가 만든 목표 플래너 앱 '역산 15분 플래너' 출시 전 테스트를 도와주실 분을 찾아요 🙏
> 마감일에서 거꾸로 중간 목표를 세우고, 15분 단위로 쪼개 오늘 할 일만 보여 주는 앱이에요.
> 안드로이드 폰만 가능하고, 아래 두 가지만 해 주시면 돼요.
> 1) 구글 그룹 가입: (그룹 링크)
> 2) 테스트 참여 후 앱 설치: (Play 테스트 링크)
> **14일 동안 앱을 지우지 말고** 가끔 열어 봐 주세요. 의견 주시면 반영할게요!

## 2. 구글 그룹 만들기 (테스터 명단 관리용)
1. groups.google.com → 그룹 만들기
2. 이름: 역산 15분 플래너 테스터 / 이메일: 원하는 주소
3. 그룹에 참여할 수 있는 사용자: **웹에 있는 모든 사용자**(링크로 가입)
4. 만든 그룹 이메일을 Play Console → 테스트 → 비공개 테스트 → 테스터 → **Google 그룹**에 입력

## 3. 14일 체크표
| 일차 | 할 일 | 확인 |
|---|---|---|
| 0 | 비공개 테스트 트랙에 .aab 업로드, 그룹 연결, 검토 제출 | ☐ |
| 1~3 | 테스터 15명 이상이 '테스트 참여' 누르고 설치했는지 확인 | ☐ |
| 7 | 작은 업데이트 1회 (예: 테스터 의견 반영) — 활발히 테스트 중이라는 근거 | ☐ |
| 10 | 테스터 수 12명 이상 유지 확인 | ☐ |
| 14 | 대시보드에서 "프로덕션 액세스 신청" 열림 확인 → 신청 | ☐ |

## 4. 프로덕션 신청 질문 답변 초안
- **테스터를 어떻게 모았나요?** 지인과 가족에게 카카오톡으로 구글 그룹 링크를 보내 모집했습니다.
- **테스터가 앱을 어떻게 사용했나요?** 시험·운동·공부 목표를 세워 거꾸로 중간 목표를 만들고, 매일 오늘의 15분 목록과 타이머로 할 일을 끝냈습니다.
- **받은 의견과 반영한 내용은?** (실제 받은 의견을 적으세요. 예: 타이머 소리가 작다 → 진동 패턴 추가)
- **앱의 대상 사용자는?** 자격증·공부·운동·업무처럼 기한이 있는 목표를 꾸준히 해내고 싶은 사람.
- **앱이 제공하는 가치는?** 큰 목표를 마감일에서 거꾸로 쪼개 매일 15분 단위의 실행 목록으로 바꿔 줍니다.
- **출시 준비가 된 이유는?** 14일 테스트 동안 오류 없이 작동했고, 테스터 의견을 반영한 업데이트를 배포했습니다.
