# 역산 15분 플래너

**한 줄 목적**: 최종 목표와 마감일을 정하면, 거꾸로 "그 직전에 이뤄져 있어야 할 중간 목표"를 세우고, 각 중간 목표를 15분 단위 할 일로 쪼개 쓸 수 있는 시간에 맞춰 날짜별로 배치한다. 매일은 '오늘의 15분 블록'만 보고 타이머로 하나씩 끝낸다.

**누가 언제**: LEE가 자격증·공부·운동·사업 준비처럼 기간이 긴 목표를 세울 때(처음 한 번 계획), 그리고 매일 폰으로 오늘 할 15분짜리를 확인하고 체크할 때.

## 핵심 기능과 완료 조건
| 기능 | 완료 조건 |
|---|---|
| 1. 목표 세우기 | 목표 이름·마감일(·이유) 입력 → 목표가 생기고, 마감일에 '최종 목표' 단계가 놓인다. 목표 여러 개를 만들고 고를 수 있다 |
| 2. 거꾸로 중간 목표 | "○○ 바로 전에 이뤄져 있어야 할 것은?"을 반복해 묻고 답을 쌓는다(맨 위가 최종 목표, 아래로 갈수록 지금에 가까움). 날짜는 제안값이 자동으로 들어가고 '고르게 나누기'로 한 번에 정리, 날짜를 고치면 순서가 자동 정렬된다 |
| 3. 15분 단위로 쪼개기 | 중간 목표마다 할 일을 적고 걸리는 시간을 15분 단위(−/+)로 정한다. 할 일은 15분 블록으로 펼쳐지고, 중간 목표마다 '쓸 수 있는 시간 안에 들어가는지'가 바로 보인다 |
| 4. 날짜별 배치 | 요일별로 쓸 수 있는 시간(15분 단위)을 정하면, 각 중간 목표의 기간 안에 블록을 고르게 나눠 날짜별 일정을 만든다. 모자라면 "○○까지 1시간 15분 모자라요"처럼 알려 주고 넘친 블록은 다음 날로 넘긴다 |
| 5. 오늘의 15분 | 오늘 배정된 블록을 타일로 보여 주고 체크하면 진행률·남은 일정이 바로 바뀐다. ▶ 15분 타이머(끝나면 진동·소리, 화면을 껐다 켜도 남은 시간이 맞음), '하나 더 하기', 밀린 블록은 자동으로 다시 배치 |
| 6. Claude에게 나눠 달라기(무료) | 목표·마감·쓸 수 있는 시간을 담은 부탁 글을 복사해 Claude 앱에 붙여넣고, 받은 답(JSON)을 붙여넣으면 중간 목표·할 일이 채워진다. API 키·서버가 필요 없다 |
| 공통 | 새로고침·앱 다시 열기 후 그대로, 백업 내보내기/가져오기, 오프라인 동작, 삭제 전 확인. 목표를 만들던 중 앱이 닫혀도(Claude 앱에 다녀오는 사이 등) 다시 열면 그 단계부터 이어서 |

## 화면 (아래 탭 4개, 한 손 조작)
- **오늘**: 목표 고르기 → D-day·전체 진행 모자이크(블록 하나 = 작은 칸) → 경고(모자람·밀림) → 오늘의 15분 타일(체크·▶타이머) → 하나 더 하기
- **역산**: 최종 목표(마감일) 카드 → 그 아래로 거꾸로 중간 목표 카드들(날짜·할 일·15분 −/+·기간 안 여유) → "이 전에 이뤄져 있어야 할 것 추가" → 고르게 나누기 · Claude에게 나눠 달라기
- **일정**: 오늘부터 날짜별 블록(할 일 이름 ×개수·시간), 중간 목표 마감 표시, 요일별 쓸 수 있는 시간 설정
- **목표**: 목표 목록(진행률·D-day)·새 목표·고르기·삭제, 백업
- 처음 열면: 빈 화면 안내 + '목표 세우기'(마법사: 목표 → 거꾸로 중간 목표 → 15분 쪼개기 → 쓸 수 있는 시간)

## 저장 데이터 (localStorage `backplan:v1`)
```
{ v: 1, current: goalId,
  goals: [{ id, title, why, deadline: "YYYY-MM-DD", createdAt,
            avail: [일,월,화,수,목,금,토 분(15의 배수)],
            steps: [{ id, title, due: "YYYY-MM-DD", final?: true, tasks: [{ id, title, blocks: 15분 블록 수 }] }],  // 날짜순, 마지막이 최종 목표
            log: [{ d: "YYYY-MM-DD", t: taskId }] }],   // 끝낸 15분 블록 하나에 한 줄 (할 일별 끝낸 수 = 이 줄 수)
  timer: { goalId, taskId, endsAt, paused, rang },   // 15분 타이머(끝 시각을 저장)
  draft: { g, page } }                                // 마법사로 만들던 목표(완료·그만두기 때 지움)
```
- 날짜는 모두 한국 시간(KST) 기준 YYYY-MM-DD.
- 일정(날짜별 배치)은 저장하지 않고 매번 계산한다. 오늘 이미 끝낸 블록도 오늘 몫에 넣어 계산하므로, 체크해도 오늘 목록이 흔들리지 않는다.

## 배치 규칙
1. 중간 목표 i의 기간 = (앞 중간 목표 마감 다음 날 또는 오늘) ~ 자기 마감일. 마감이 지났는데 남은 블록이 있으면 오늘부터 바로.
2. 기간 안의 날마다 쓸 수 있는 블록 수(요일별 시간 ÷ 15분)를 넘지 않게, 남은 블록을 남은 날에 고르게(앞쪽부터 올림) 나눈다.
3. 기간 안에 다 못 넣은 블록은 '모자람'으로 표시하고 마감 다음 날부터 이어서 넣는다(일정이 끊기지 않게).
4. 마감일 뒤로도 넘치면 '마감까지 못 끝냄 · 하루 ○분 더 필요'로 알린다.

## 목표까지 연동 (10/11 재개, LEE가 '자동 연동' 선택)
LEE의 계획은 아티팩트 '목표까지 자산 플래너'(인생 목표 7개: 단계·수치·평일 하루 분량)에 있다. 역할을 나눈다:
- **목표까지 = 무엇을·언제까지**: 목표 이름·기한·중간 단계(날짜)·하루 분량은 목표까지에서 고친다. 폰에서는 읽기만.
- **역산 플래너(폰) = 어떻게·오늘**: 오늘 할 하루 분량과 15분 할 일을 타일로 보고 체크·타이머. 단계마다 15분 할 일을 더 쪼갤 수 있다. 목표까지에 없는 목표는 폰에서 예전처럼 거꾸로 세운다.
- **동기화 서버**: LEE의 Cloudflare Worker `backplan` + KV(`BP`) + 비밀 `ACCESS_CODE`.
  - 폰 ↔ 서버: `GET/PUT /api/sync` (접속 코드 머리글, rev로 덮어쓰기 막음). 폰 데이터 전체(목표·할 일·체크 기록)와 진행 요약을 올린다.
  - 목표까지 ↔ 서버: claude.ai 사용자 지정 연결 **'역산플래너'** (`/mcp`, MCP Streamable HTTP, 인증 없음 + 도구마다 접속 코드). 도구 `sync_goals`(목표·단계·앞으로 120일 하루 분량을 보내고 폰 진행을 받음), `get_progress`(읽기).
- **목표까지의 '역산 플래너와 맞추기' 버튼**: ① 단계·수치에 고유 id(sid·mid) 붙이기 ② 목표·단계·하루 분량(목표까지 달력과 같은 계산) 보내기 ③ 폰 진행 받아 반영 — 폰에서 '끝냄'으로 표시한 단계는 완료, 누적 수치는 폰에서 체크한 양을 달마다 더해 '실제 누적'에 채움(손으로 적은 달은 그대로 두고 그 값부터 이어 셈) ④ 저장.
- **폰에서 받은 목표**: 단계는 목표까지 그대로(이름·날짜 고정, '끝냄' 표시만), 최종 목표 = 목표까지 목표·기한. 하루 분량 타일은 한 번에 기본 15분(시간 단위면 그 시간), 수치마다 '한 번에 ○분'을 폰에서 바꿀 수 있다. 체크한 양은 15분 칸 비율로 실적이 된다. 목표까지에서 지우거나 완료·보류하면 폰 오늘 화면에서 빠진다.
- **여러 기기**: 서버 rev가 앞서 있으면 받아서 합친다(목표별로 나중에 고친 쪽, 체크 기록은 합집합, 지운 목표는 표시를 남겨 되살아나지 않게).
- **모든 목표 보기**: 목표가 둘 이상이면 오늘·일정 화면에 '모든 목표'(목표별로 묶은 오늘 타일). 역산은 목표 하나씩.

## 10/11 밤 추가 — 새 목표·날짜 바꾸기·순서도 (LEE 요청, 순서도는 시안 B 선택)
- **역산 화면 '목록 | 순서도'** (기본 순서도, 고른 보기는 기기에 기억). 순서도 = 맨 위 최종 목표 → 단계(늦은 날짜부터) → 오늘 → 지난 단계. 화살표는 하는 순서(아래→위), 사이 숫자는 날 수, 단계마다 15분 할 일이 오른쪽 가지(□ 한 칸 = 15분, 끝낸 칸은 칠함, 4개 넘으면 '더'), 다음 단계 노란 테두리·마감 지남 빨간 테두리·바꾼 날짜 노란 바탕. 상자를 누르면 날짜 바꾸기, '오늘'은 오늘 화면으로.
- **날짜 바꾸기**: 목표 화면 '마감 바꾸기'(폰 목표는 중간 목표도 같은 비율로), 순서도 상자, 목록의 날짜 칸, 마감 지남 알림의 '날짜 고치기'. 목표까지 목표도 날짜는 폰에서 바꿀 수 있다(이름은 목표까지에서).
  - 폰: `mkEdit {due:{from,to}, steps:{sid:{from,to}}}`(from = 바꿀 때의 목표까지 값) → 진행 `progress.goals[id].edits`로 보냄. 새 스냅숏 값이 to면 지움(반영됨), from이면 유지(아직), 다른 값이면 목표까지를 따르고 알림.
  - 목표까지: 맞추기 = get_progress → 폰의 새 목표·날짜 반영 → 스냅숏 → sync_goals → 진행 반영 → 저장. 날짜는 폰이 새로 올린 진행일 때만(`bpPhoneAt`), 그리고 지난번 보낸 값(`bpSent`)과 같을 때만 반영 — 목표까지에서 그사이 고친 날짜를 폰의 옛 편집이 덮지 않게.

## 10/12 — 할 일 없는 중간 목표가 조용히 빠지던 문제 (LEE 문의: 한식요리자격증이 오늘 화면에 없음)

## 10/21 — 요일별 시간 · 마감 순 · 낮은 칸 · 드롭다운 (LEE 요청: "프로젝트마다 월~일 시간을 골라 매일 보여 주고, 칸 높이 줄이고, D-day 적은/지난 것부터, 시간은 드롭다운, D-day 크게")
- **요일별 시간 = 그 요일 오늘 칸 수.** 목표마다 월~일 시간(`avail`, 0=쉼·15분~12시간)을 고르면, 그 요일 오늘 화면에 시간÷15분만큼 15분 칸이 나온다. 0분(쉼)인 요일엔 그 목표가 오늘 화면에 안 나온다(모든 목표: '오늘 쉬는 목표: …' + 요일별 시간 / 목표 하나: '오늘(○요일)은 이 목표를 쉬는 날이에요' + '＋ 15분 하기').

## 10/23 — 새 순서(목표일 → 단계·일별·운동) · 밀린 것 · 완료 보관 (LEE 요청)
요청 요지: "부가세 신고는 어제 다 했는데 오늘도 나온다 / 오늘은 어제·그전에 못 한 것을 함께 보여 독려 / D+ 목표는 밀린 것을 다 체크하면 완료로 없애고 따로 보관 /
1. 프로젝트를 만들 때 D-day를 묻고 목표일로 / 2. 세부 목표는 일별·sub목표 중 고르기(sub목표: 목표일마다 구간을 나눠 지정한 날에 / 일별: 전체 횟수 → 한 달 20일 기준 + 할증 20%로 시작일, 늦으면 시작 D-day와 '이 프로젝트의 실행은 ○월 ○일에 시작될 예정입니다.', 1/전체횟수로 미리 적고 끝낸 뒤 제목 고치기) /
3. 이 순서를 거치지 않은 것은 일정·목표·역산엔 구분해서 보이고 오늘엔 안 나옴 / 4. 운동은 목표·처음 실행 가능치를 묻고 변화 곡선으로 회차마다 나누기"
- **설정(plan)** 목표마다 `plan: {kind: 'steps'|'daily'|'ramp', at(설정한 날), …}`. 설정 전 목표(plan 없음: 예전 목표·목표까지에서 온 목표)는 오늘 화면에 안 나오고 '설정 전 목표 n개' 목록(설정하기 버튼)으로만. 일정(흐리게 '설정 전')·역산(설정 전 안내)·목표(점선 카드·'설정 전' 표시)에는 구분해서 보인다.
- **마법사 4단계**: 1 최종 목표·목표일(D-day 바로 표시) → 2 나누는 방식(단계·일별·운동 카드) → 3 세부 → 4 확인. '설정하기'/'설정 바꾸기'도 같은 순서(그 목표의 사본을 고쳐 끝나면 바꿔 넣음, 체크 기록은 그대로). 목표까지 목표는 이름·단계가 그대로이고 목표일만 바꿀 수 있음(목표까지로 돌아감). 15분 할 일로 쪼개기는 마법사에서 빼고 역산 → 목록에서(적으면 칸이 그 할 일로 채워짐).
- **단계(steps)**: 중간 목표마다 목표일 → 앞 목표일 다음 날~자기 목표일이 그 단계의 구간. 고른 요일(요일별 시간 > 0)에 그 구간의 단계가 시간만큼 15분 칸으로(10/21 규칙 그대로).
- **일별(daily)**: 필요한 달 = 횟수 ÷ (한 달에 하는 날: 주 5일 = 20일, 주 k일 = 4k일) × 1.2(여유 20%), 1달 = 30일 → 목표일에서 그만큼 거꾸로가 시작일(`from`). 늦으면 시작 D-day와 '이 프로젝트의 실행은 ○월 ○일에 시작될 예정입니다.'(마법사·오늘·목표·역산), '오늘부터 시작'으로 당길 수 있음. 오늘보다 앞이면 오늘 시작(모자라면 하루 2회 이상인 날 + 안내). 고른 요일(기본 월~금)에 하루 한 회차씩 날짜(`dates`)를 정해 둔다(남는 날은 목표일 앞 여유).
  - 오늘 줄: `k/N` + (운동은 그 회차 양) · 끝낸 회차는 ✎로 1/N 뒤에 붙일 제목(`slog: [{id, k, d(한 날), t(제목)}]`). 오늘 회차를 다 하면 '＋ 다음 회차 미리 하기'.
  - 하는 요일·목표일을 바꾸면 끝내지 않은 앞으로의 회차만 다시 놓음(지난날 못 한 회차는 밀린 것으로 남김).
- **운동(ramp)**: 무엇을·최종 목표(b)·단위·지금 할 수 있는 양(a)·전체 횟수·하는 요일·곡선. k회차 양 = a + (b−a)·f((k−1)/(N−1)), f = S자(smoothstep: 처음·끝 천천히, 기본) 또는 직선. 소수 자릿수는 넣은 값을 따름. 제목 '팔굽혀펴기 50개'에서 이름·목표·단위를 짐작해 미리 채움. 날짜는 일별과 같은 규칙. 곡선 그림(마법사·오늘·역산).
- **밀린 것**: 오늘 화면에 오늘 몫과 함께, 오래된 것부터. 일별·운동 = 날짜가 지난 끝내지 않은 회차. 단계 = 설정한 날(시작일)부터 어제(목표일이 먼저면 목표일)까지 고른 요일마다 시간만큼 못 채운 15분 칸(끝낸 단계의 구간은 뺌) — 나중에 하면 그날 몫으로 기록(`dlog`에 `d`=그날, `at`=한 날). 독려 문구 '어제 못 한 것 n개 · 그전에 밀린 것 m개 — 오늘 같이 끝내 봐요!', 오늘 머리·묶음 머리에 '밀린 n'. 8개 넘으면 '밀린 것 n개 더 보기'.
- **완료 보관(doneAt)**: 일별·운동은 모든 회차를 하면, 단계는 목표일이 지나고(D+) 밀린 칸을 다 하면 바로 완료 → '완료 보관함'(목표 화면 아래, 되돌리기·지우기). 오늘 화면엔 '오늘 완료한 목표 ✓'. 손으로 '목표 완료로 보관'도(오늘·목표 카드). 다른 기기에서 다 한 것도 화면을 그릴 때 옮김. 되돌린 목표(`reopen`)는 자동으로 다시 옮기지 않음.
- 목표까지로 보내는 15분 기록에 회차도 한 번에 15분으로 더함. 여러 기기 합치기: 회차 기록은 합집합(같은 회차는 나중에 고친 쪽).
- 정한 것: 단계 목표의 '지정한 날'은 프로젝트의 요일별 시간(10/21)으로 함(단계마다 따로 정하지 않음). 일별·운동 기본 요일은 월~금(= 한 달 20일). 한 달 = 30일. 설정 전 목표는 오늘 화면에 안 나옴(목표까지에서 온 목표도 '설정하기'를 해야 나옴). 마감이 지난 단계 목표에 밀린 칸이 하나도 없으면(다 했으면) 바로 보관함으로.
- 검수: 새 흐름 5개(일별 시작일·문구·시작 D-day·회차 목록 / 밀린 회차·독려·제목 고치기 / D+ 밀린 것 다 하면 보관·되돌리기 / 회차를 다 하면 보관 / 운동 곡선·제목 짐작) + 옛 저장본(설정 전 구분·설정하면 나옴) + 바뀐 흐름(마법사 순서·목표까지 목표 설정하기). 서비스워커 `backplan-v8`.
