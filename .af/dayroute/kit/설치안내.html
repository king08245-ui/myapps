1. 일정 계산 서버 만들기 (Cloudflare Worker)

1dash.cloudflare.com에 로그인 → 왼쪽 메뉴 Workers 및 Pages(Workers & Pages) → 생성(Create) → Worker 만들기(Hello World로 시작) → 이름을 dayroute로 바꾸고 배포(Deploy).
2코드 편집(Edit code)을 누르고, 왼쪽에 있는 코드를 모두 지운 뒤 이 폴더의 cloudflare/worker.js를 메모장으로 열어 전부 복사해 붙여넣기 → 오른쪽 위 배포(Deploy).
3Worker 화면 → 설정(Settings) → 변수 및 비밀(Variables and Secrets) → 추가(Add)를 눌러 아래 4개를 종류: 비밀(Secret)로 넣고 배포(Deploy).
이름값
KAKAO_REST_KEYPC의 다운로드\하루동선\dayroute-app\.env를 메모장으로 열어 같은 이름 뒤의 값
ODSAY_API_KEY위 .env의 같은 이름 뒤의 값
KAKAO_JS_KEY위 .env의 같은 이름 뒤의 값 (지도용)
ACCESS_CODE남이 짐작 못 할 말로 6자 넘게 (예: 단어 두 개를 붙여서 파란우산여름밤처럼). 한글도 돼요. 폰 앱에 같은 값을 넣어요. 남이 내 키 사용량을 못 쓰게 막는 용도

키 값은 이 칸에만 넣으세요. 채팅이나 다른 곳에 붙여넣지 마세요.

4Worker 화면 위쪽에 보이는 주소(https://dayroute.○○○.workers.dev)를 눌러 열어 보세요. “하루동선 서버가 동작 중이에요”가 나오면 성공이에요. 이 주소를 복사해 두세요.
