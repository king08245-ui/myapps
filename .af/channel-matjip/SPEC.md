# 채널 맛집수첩 (폰 앱판)

**한 줄 목적**: 즐겨 보는 유튜브 맛집 채널(백년해방·술맛여행놈·쇼리뷰 + 10/14 맛삼인·쏘울맛집·하이갱스·서울 사는 남자 + 10/18 셰프이원일)이 소개한 가게를 동네·메뉴로 찾고, 지금 있는 곳에서 가까운 순으로 본다.

**누가 언제**: LEE가 밖에서 폰으로 "이 근처에 그 유튜버가 간 집 있나?" 할 때. 집에서 다음 갈 곳을 고를 때.

## 원본(아티팩트 '채널 맛집수첩')에서 이어받는 기능
| 기능 | 완료 조건 |
|---|---|
| 동네로 찾기 | "종로3가" 입력 → 주소·영상 제목·지역 메모에 그 동네가 들어간 가게가 나온다 |
| 메뉴로 찾기 | "순대국" → 순댓국·순대국밥 표기까지 찾는다. 'BEST 10' 묶음 영상의 제목은 1~2곳 영상일 때만 메뉴로 본다(간짜장 → 홍두깨국수가 나오던 버그 재발 금지) |
| 채널 켜고 끄기 | 칩을 누르면 그 채널 가게가 빠지고, 다시 열어도 기억 |
| 내 위치 + 가까운 순 | 프리셋 6곳(공덕역 기본)·직접 입력, 1km/3km/10km 묶음, 가게마다 거리 |
| 내 근처 전체 보기 | 위치를 아는 가게 전부, 가까운 순(10/13부터 거리 제한 없음) |
| 지도로 보기 | 구 경계·이름·한강·주요 역이 그려진 SVG 지도에 채널 색 점, 확대/축소/이동, 점 누르면 지도에 이름 + 아래 카드 |
| 구글지도에서 보기 | 가까운 9곳을 구글지도 경유지로 |
| 가게 카드 | 영상 그 장면(타임스탬프), 네이버지도·카카오맵·구글지도 링크 |

## 폰 앱판에서 바뀌는 것
- **홈 화면 설치·오프라인**: manifest, 서비스워커, 아이콘. 가게 데이터와 지도도 폰에 저장돼 지하철에서도 열린다.
- **현재 위치(GPS)**: 폰 위치로 가까운 순 정렬. 권한이 없으면 역 선택으로.
- **가게 좌표 정밀화**: 주소 1,246곳을 OpenStreetMap으로 좌표 변환(지난 대화에서 끝나지 않은 작업) → 10/11 카카오로 다시 변환(아래). 정확한 좌표가 없는 가게만 "약" 표시.
- **Claude 연결 기능 대체**: 아티팩트에서는 Claude가 검색어를 넓혀 줬지만, 폰 앱에는 Claude가 없다. 대신
  - 메뉴: 동의어 사전(순대국↔순댓국, 짜장↔간짜장·중국집 등)
  - 동네: 역·동네 좌표 사전 + 반경 1km 안 가게 포함
  - 목록에 없는 장소 이름: 무료 지도 검색(Photon)으로 좌표 찾기(인터넷 필요)

## 화면
머리글(설치 버튼) → 찾는 방식(동네/메뉴) + 검색 → 내 위치(현재 위치·프리셋·입력) → 채널 칩 → 결과(목록/지도) → 데이터 기준일·개인정보처리방침

## 2차 검수 뒤 바뀐 것
- **가게 묶기**: 같은 채널에서 이름이 비슷하고(같음·포함·한 글자 차이) 장소가 같은(같은 주소, 또는 주소 좌표가 1km 안) 줄을 한 가게로 묶는다. 이름만 같고 장소가 다른 가게(대박분식 서울·부산, 원성반점 서울·강릉)는 따로 둔다. 주소 없는 줄은 같은 이름의 가게 중 대략 위치가 닿는 곳(구 8km·동네 4km·도시 30km)에만 붙인다. 카드 수 1,835줄 → 가게 1,454곳(채널별, 카카오 좌표 뒤 1,444곳).
- **좌표 바로잡기**: 무교동북어국집·우래옥은 관광공사 좌표로 고침, 같은 주소인데 좌표가 다른 3곳(황학동 707-1, 백촌막국수, 금성문)은 더 정밀하고 더 많은 줄이 가리키는 좌표로 맞춤. 서울 구 경계 검사에서 큰 오류 없음.
- **동네 검색 범위**: 영상 제목에만 동네 이름이 있는 가게는, 주소가 없거나 그 곳 가까이(동네 4km·도시 15km) 있을 때만 넣는다("속초부터 부산까지" 영상의 속초 가게가 부산 검색에 나오지 않게). 같은 이름의 다른 도시 동네·구(부산 중구 등)는 빠진다.
- **구글지도 경로**: 기준 위치(찾은 곳 또는 내 위치)에서 10km 안 가게만, 내 위치가 30km 안일 때만 내 위치에서 출발. 기준이 없으면 버튼을 숨긴다.
- **화면**: 지도 점을 누르면 카드가 보이게 스크롤, 동네 검색 중에는 "지금 결과는 찾은 곳 기준" 안내, 1km→3km로 넓히면 그렇게 표시, 아직 안 찾은 입력은 모드를 바꿔도 남기고 바로 찾기, 역 58개 추가(인터넷 없이 찾기).
- **약한 신호**: 화면은 3초 안에 새것이 안 오면 저장본으로 열기(서비스워커 v2), 글꼴은 화면을 막지 않게 받기, 장소 찾기는 6초에서 멈춤.

## 카카오 좌표로 다시 찍음 (10/11, 서비스워커 v3)
- 주소 1,246곳을 LEE의 PC에서 카카오 주소 검색으로 다시 변환(키는 PC의 .env에서만 읽음): 1,236곳이 번지까지 찾음, 10곳은 못 찾아 기존 좌표 유지.
- 번지까지 정확한 좌표(정밀도 1) 532 → 1,465줄, 지역 수준 좌표(정밀도 3) 401 → 3줄. 주소는 있는데 좌표가 없던 120줄에 새로 좌표(주소가 없는 360줄은 그대로 동네 이름으로 대략 위치). 무교동북어국집·우래옥 손으로 고친 좌표는 카카오와 10m 안에서 일치.
- 좌표가 정확해져 가게 묶기 1,454 → 1,444곳(같은 채널의 '속초 동명항 오징어난전'·'오징어난전' 같은 줄이 하나로). 종로3가 1km 안 84 → 107곳(삼해집 110m 등 좌표가 없던 가게), 명동교자처럼 1km 밖 가게는 빠짐.
- 도시 검색: 정확한 좌표의 가게도 영상 제목에 그 도시가 있고 15km 안이면 넣는다(속초 영상의 고성 토성면 어글리패티가 정확한 좌표가 되자 빠지던 문제).

## 10/13 — 지도 이름표·거리 제한 없음·구 경계 (LEE 요청, 서비스워커 v4)
- **점을 누르면 지도에 가게 이름 말풍선**: 지도 위쪽 끝이면 점 아래에, 좌우 끝이면 말풍선을 안쪽으로 밀어 잘리지 않게. 확대·이동해도 남고, 빈 곳을 누르면 사라짐. 아래 카드는 그대로.
- **'내 근처 전체 보기' 3km 제한 없앰**: 위치를 아는 가게 전부(약 1,400곳)를 가까운 순으로. 목록은 40곳씩 '더 보기', 지도는 처음에 15km 안을 비추고 '전체'로 전국. 대략 위치 가게는 3km 안이면 3km 묶음 뒤 '대략 위치' 묶음, 더 멀면 거리 묶음에 함께(전국 가게 뒤로 밀리지 않게). 동네 검색 반경(1km, 적으면 3km)은 '그 동네 찾기'라 그대로.
- **서울 25개 구 경계와 이름**: 경계선을 진하게, 맞닿은 구끼리 다른 옅은 바탕색(4가지). 구 이름은 구의 가장 안쪽 점에, 확대해서 가운데가 화면 밖이면 화면에 보이는 부분 안쪽에. 가게 점이 적은 자리를 골라 점 위에 그림(이름은 눌리지 않아 점은 그대로 누를 수 있음). 역·내 위치·한강 글자·다른 구 이름·고른 가게 말풍선과 겹치지 않게.
- 화면 밖 점은 그리지 않음(전국 가게를 띄워도 끌기·확대가 가볍게).
- 검수: QA 31개 FAIL 0(새 검수: 거리 제한 없이 전부·묶음 순서 / 이름 말풍선 / 구 바탕색·이름·겹침).

## 10/13 밤 — 가 본 집·확대하면 가게 이름 (LEE 요청, 서비스워커 v5)
- **가 본 집**: 카드의 '가 봤어요'를 누르면 카드가 회색 + '✓ 가 봤어요', 지도 점도 회색(범례 '가 본 집'), 지도 이름·말풍선에 ✓. 같은 가게면 채널이 달라도 함께 표시(이름 + 주소 도로명·번지, 주소가 없으면 동네). 다시 누르면 지움. 지도에서 바꿔도 확대·위치 그대로.
- 기기에 저장(`cfn.visited`) + 맨 아래 '가 본 집 내보내기/가져오기'(폰이면 공유, 가져오기는 지금 목록에 더하기만).
- **확대하면 가게 이름**: 지도 폭이 약 3.6km 이하로 확대되면 고르지 않아도 점 위(자리가 없으면 아래)에 가게 이름. 겹치는 이름은 빼고 화면 가운데·정확한 위치 가게 먼저, 더 확대하면 더 많이. 고른 가게는 말풍선 하나로만, 구 이름은 가게 이름을 피해서.
- 검수: QA 33개 FAIL 0(새 검수: 확대 시 이름·겹침·축소 시 사라짐 / 가 본 집 표시·새로고침·지도·백업).

  - 이름으로 찾은 가게는 제목의 시·도/시·군·구 안(주소로 확인, 경계 3km까지)일 때만 — '대전 봉명동' 영상에 청주 봉명동 가게가, '서울 ○○' 영상에 광명 가게가 붙던 것을 막음.
- **서울 사는 남자는 6곳뿐**: 가게 목록을 네이버 지도 모음집(naver.me) 링크로만 올리는데, 내장 브라우저가 map.naver.com을 안전 제한으로 열지 않음. 설명란에 이름이 적힌 가게(쇼니노·스시 유타카·봉천다찌·행복한점·이목스모크다이닝·산재우)만 넣음.
- **가게 종류**: 카카오 분류의 끝말(예: 냉면·국수·중국요리)을 places 8번째 칸에 넣고 카드에 '🍴 냉면'으로, 메뉴 검색에도 씀(이름에 메뉴가 없는 가게도 찾아짐). 기존 채널 가게 1,095줄에도 붙임.
- **채널 색 7개**: 기존 빨강·파랑·초록 그대로 + 황토(맛삼인)·보라(쏘울맛집)·자주(하이갱스)·청록(서울 사는 남자). 7색은 모든 쌍을 색만으로 뚜렷이 가를 수 없어(검사 도구 기준 미달 — 특히 청록↔파랑, 빨강↔황토는 색약에 비슷) 채널 이름표를 '본문색 글자 + 색 점'으로 바꾸고(노랑·연보라 글씨가 안 읽히던 문제도 해결), 채널 버튼으로 보고 싶은 채널만 켜서 보게 함. 범례는 지도 아래쪽 두 줄.
- **지도**: 점이 3,000개 넘게 깔려 구 이름 자리가 모자라 → 구 이름은 그 구 안쪽 자리를 우선(점이 적은 자리는 덜 중요하게), 화면 가운데(찾은 곳) 가까운 구부터 놓음. 서울 전체가 보일 만큼 넓게 볼 때는 '한강' 글자를 빼서(점에 가려짐) 구 이름 자리로 씀. 공덕역 기준 지도에서 구 이름 24/25개(강동구만 화면 끝이라 빠짐).
- **목록 '더 보기'**: 이미 만든 카드는 다시 쓰고 새 카드만 만듦(내 근처 전체 4,800여 곳을 끝까지 펼쳐도 느려지지 않게).

  - 몰아보기 영상(만두·짬뽕 지침서, 중식 마스터, 돈까스 통합편)은 원래 영상과 자막을 비교해 새로 붙은 부분만 읽음 → 역삼 속초집·명동 산동교자·원동반점·띠디 추가.
  - 자동 자막은 이름이 틀리게 들리는 일이 많아(동숙 뜬다→동승루, 파워파워→파오파오, 바로베→다로베, 청간→성천막국수, 홍로원→홍루원, 라이→라이라이),
    영상에서 말한 지역 안에서 카카오 장소 검색으로 하나씩 확인한 가게만 넣음. 확인 못 한 이름(원래순·아리랑돈가스·오꽃·동키돈가스)과
    셰프가 '아직 못 가봤다'고 한 집(혼돈·우메돈·교카이젠), 이름만 스친 구독자 제보(브네·카와카츠), 체인 배달(잭슨피자·파파존스·고피자)은 뺌.
  - 메모에 '(구독자 추천)'·'(카페 사장님 추천)'을 붙여 셰프 본인 추천과 구분. 옮긴 가게는 지금 위치(노독일처 마포, 홍보각 노보텔 강남, 이원일식탁 서래마을, 양각도는 상암점이 카카오에 없어 일산본점).

## 저장 데이터
- 기기 저장(localStorage): `cfn.origin`(내 위치), `cfn.off`(끈 채널), `cfn.view`(목록/지도) — 원본과 같은 키
- `cfn.visited`(가 본 집 키 목록, 10/13부터) — 내보내기/가져오기 가능
- 가게 데이터: `places.json` {channels, videos[[id,제목,날짜,채널]], places[[이름,설명,주소,지역메모,영상번호,초,좌표|null,가게종류]]} — 좌표는 [위도,경도,정밀도 1~3], 가게종류는 카카오 분류 끝말(예: 냉면, 중국요리, 없으면 "")
- 채널 색은 채널 순서(channels 배열)대로 --c1~--c8 고정. 새 채널은 배열 끝에 붙인다(기존 채널 색이 바뀌지 않게)
