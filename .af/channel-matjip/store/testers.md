# 비공개 테스트 안내 — 개인 개발자 계정용

새 개인 계정은 **테스터 12명 이상이 14일 연속** 참여한 비공개 테스트를 마쳐야 정식 출시(프로덕션) 신청이 열립니다. 중간에 빠져 12명 아래로 내려가면 14일이 다시 시작될 수 있으니 **15~20명**을 모으세요.

## 1. 테스터 모집 카톡 문구 (복사해서 보내기)
> 안녕하세요! 제가 만든 맛집 앱 '채널 맛집수첩' 출시 전 테스트를 도와주실 분을 찾아요 🙏
> 유튜브 맛집 영상에 나온 가게를 동네·메뉴·가까운 순으로 찾는 앱이에요.
> 안드로이드 폰만 가능하고, 아래 두 가지만 해 주시면 돼요.
> 1) 구글 그룹 가입: (그룹 링크)
> 2) 테스트 참여 후 앱 설치: (Play 테스트 링크)
> **14일 동안 앱을 지우지 말고** 가끔 열어 봐 주세요. 의견 주시면 반영할게요!

## 2. 구글 그룹 만들기 (테스터 명단 관리용)
1. groups.google.com → 그룹 만들기
2. 이름: 채널 맛집수첩 테스터 / 이메일: 원하는 주소
3. 그룹에 참여할 수 있는 사용자: **웹에 있는 모든 사용자**(링크로 가입)
4. 만든 그룹 이메일을 Play Console → 테스트 → 비공개 테스트 → 테스터 → **Google 그룹**에 입력

## 3. 14일 체크표
| 일차 | 할 일 | 확인 |
|---|---|---|
| 0 | 비공개 테스트 트랙에 .aab 업로드, 그룹 연결, 검토 제출 | ☐ |
| 1~3 | 테스터 15명 이상이 '테스트 참여' 누르고 설치했는지 확인 | ☐ |
| 7 | 작은 업데이트 1회 (예: 새 영상 반영) — 활발히 테스트 중이라는 근거 | ☐ |
| 10 | 테스터 수 12명 이상 유지 확인 | ☐ |
| 14 | 대시보드에서 "프로덕션 액세스 신청" 열림 확인 → 신청 | ☐ |

## 4. 프로덕션 신청 질문 답변 초안
- **테스터를 어떻게 모았나요?** 지인과 가족에게 카카오톡으로 구글 그룹 링크를 보내 모집했습니다.
- **테스터가 앱을 어떻게 사용했나요?** 외출 중 '현재 위치'로 근처 맛집을 찾고, 동네·메뉴 검색과 지도 보기를 사용했습니다.
- **받은 의견과 반영한 내용은?** (실제 받은 의견을 적으세요. 예: 검색 결과 글씨가 작다 → 크기 조정)
- **앱의 대상 사용자는?** 유튜브 맛집 영상을 즐겨 보고, 영상에 나온 가게를 실제로 찾아가려는 성인.
- **앱이 제공하는 가치는?** 여러 영상에 흩어진 가게 정보를 동네·메뉴·거리로 한 번에 찾게 해 줍니다.
- **출시 준비가 된 이유는?** 14일 테스트 동안 오류 없이 작동했고, 테스터 의견을 반영한 업데이트를 배포했습니다.
